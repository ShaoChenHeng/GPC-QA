# GPC-QA

**A Controlled Chinese Question Answering Resource for Government Procurement**

GPC-QA is a domain resource for Chinese government procurement question answering. It is built from real procurement cases and expert questions, and aligned with national procurement statutes. The resource is designed for research on legal-domain retrieval, domain adaptation, and citation-grounded generation.

## At a glance

- **13,954** question--answer pairs
- **43** national laws and **1,224** statutory articles
- Objective statutory question answering and subjective legal reasoning
- Article-level statutory citation annotations

## Data sources

The subjective questions are derived from real procurement cases and expert questions from the China Government Procurement Network (https://www.ccgp.gov.cn/). Statutory texts are taken from the National Database of Laws and Regulations (https://flk.npc.gov.cn/).

## Release scope

The public release includes:

- data processing, training, inference, and evaluation code;
- the fine-tuned model.

The crawler code is **not** released. Raw GPC-QA data is **not** redistributed because of copyright and usage restrictions of the source platform. GPC-QA is therefore a controlled evaluation resource, not a public corpus.

## Data availability

The raw corpus is not included in this repository, and no data download link is provided. Use of the raw data is subject to the source platform's terms.
